Caméra éteinte
✌︎

Activez la caméra pour essayer les gestes.

Gardez le geste un instant. Ouvrez la main avant de le répéter.

Faites le signe de paix pour copier, puis le signe rock pour coller. Vous pouvez aussi cliquer sur les raccourcis.

Copier utilise la sélection ou toute la note. Pour coller, levez l’index et l’auriculaire et repliez les autres doigts sous le pouce.

Le texte et le presse-papiers restent dans la démo. La caméra est traitée sur votre appareil.

À propos de la confidentialité

Ce portfolio n’utilise ni outil d’analyse, ni cookie publicitaire, ni chatbot. Les commandes gestuelles traitent les images localement dans votre navigateur. La caméra s’arrête lorsque vous désactivez les commandes, appuyez sur Échap ou quittez l’onglet. Votre préférence de langue est enregistrée sur cet appareil. Les liens vers les projets ouvrent des sites ayant leurs propres politiques.
