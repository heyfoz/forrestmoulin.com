Catatan kecil tentang privasi

Portofolio ini tidak memiliki analitik, cookie iklan, atau chatbot. Kontrol tangan opsional memproses bingkai kamera secara lokal di browser Anda. Kamera berhenti saat Anda mematikan kontrol, menekan Escape, atau meninggalkan tab. Preferensi bahasa disimpan di perangkat ini. Tautan proyek membuka situs web terpisah dengan kebijakan mereka sendiri.
